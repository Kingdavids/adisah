# Adisah African Store website

Next.js 16 + Tailwind 4, hosted on Railway. Store details live in `lib/site.ts`.

```bash
npm install
npm run dev
```

Routes: `/` home, `/order` WhatsApp order builder, `/reviews` printable review QR card, `/review` redirect to the Google review link.

Environment variables are listed in `.env.example`. Google setup steps are in `docs/setup-checklist.md`, and the questions for the owner are in `docs/discovery-questions.md`.
